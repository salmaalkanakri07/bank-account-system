# Bank Account System

A beginner-friendly Python project for practicing OOP, functions, JSON, and basic file handling.

## Features

* Create an account
* Login
* View balance
* Deposit money
* Withdraw money
* Transfer money
* View transaction history
* Delete an account

## What I Practiced

* Object-Oriented Programming
* Functions
* JSON
* Lists and dictionaries
* Basic file handling
* Input validation
